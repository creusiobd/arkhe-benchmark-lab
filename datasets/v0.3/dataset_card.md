# Dataset Card: ARKHÉ Agent Boundary Defense Benchmark v0.3

## Dataset Summary
A standardized multi-agent trajectory benchmark designed to evaluate trajectory-aware observability against isolated event rule-based and semantic guardrail baselines.

## Supported Security Boundaries
1. `INDIRECT_PROMPT_INJECTION`
2. `TOOL_SCOPE_EXPANSION`
3. `SECRET_EXPOSURE`
4. `UNAUTHORIZED_EXTERNAL_COMMUNICATION`
5. `HUMAN_INTERVENTION_BYPASS_OR_CONCEALMENT`
