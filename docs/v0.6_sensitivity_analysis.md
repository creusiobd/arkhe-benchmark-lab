# ARKHÉ v0.6 — prospective sensitivity analysis

**Evidence stage:** design only  
**Test outcomes used:** none  
**Primary test:** exact two-sided McNemar, positive-direction power  
**Decision status:** selected before v0.6 case authoring

## Question

Can the planned paired study detect a 15-percentage-point correctness advantage for
ARKHÉ with at least 80% power at `alpha = 0.05`?

McNemar power depends not only on sample size and effect difference, but also on the
total probability that the two detectors disagree in correctness. Let:

- `q` be total discordance;
- `p10` be the rate at which only ARKHÉ is correct;
- `p01` be the rate at which only the comparator is correct;
- `delta = p10 - p01 = 0.15`.

For each sensitivity scenario, `p10 = (q + delta) / 2` and
`p01 = (q - delta) / 2`. The calculation integrates over the random number of
discordant pairs and applies the exact two-sided McNemar rejection boundary. It does
not use v0.5 outcomes as an independent prior.

## Reproducible results

Run:

```bash
python scripts/analyze_v06_sensitivity.py
```

| Total discordance `q` | ARKHÉ-only correct | Comparator-only correct | Power at `n=200` | Minimum `n` for 80% |
|---:|---:|---:|---:|---:|
| 0.20 | 0.175 | 0.025 | 99.91% | 72 |
| 0.30 | 0.225 | 0.075 | 97.41% | 112 |
| 0.40 | 0.275 | 0.125 | 91.12% | 147 |
| **0.50** | **0.325** | **0.175** | **83.64%** | **183** |
| 0.60 | 0.375 | 0.225 | 76.11% | 219 |

For comparison, `n=160` provides only 73.84% power at `q = 0.50`.

## Design decision

The protocol selects **200 trajectories**, with 50 per family and a 20/15/15
benign/near-violation/violation allocation. The design scenario is `q = 0.50`, where
exact power is 83.64%. This adds a 17-case margin over the exact minimum of 183 while
preserving equal family and class allocation.

The 60% discordance scenario remains below 80% and is disclosed rather than hidden.
There will be no outcome-driven sample expansion. If an independent protocol review
requires power at `q = 0.60`, the sample plan must be amended and approved before any
v0.6 test case is authored or inspected.

## Interpretation boundary

This analysis justifies a planned sample under explicit assumptions. It is not an
observed result, does not establish detector effectiveness, and does not make the
synthetic study equivalent to production validation.
